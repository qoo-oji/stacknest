# StackNest の参照ファイル（.stacknestbook）

**日本語** | [English](book-reference-format.en.md)

外部ビューアの作者向けの文書は、**StackNestViewerKit のリポジトリに移りました**。対応の宣言・型・参照ファイルの中身・本の API・名乗りのヘッダ・読まれたかの確認・ビューアへのお願い・セキュリティ上の注意・版の扱いは、すべてそちらに書いています。

- 形式の文書: [Documentation/BookReferenceFormat.md](https://github.com/shelfsmith/StackNestViewerKit/blob/main/Documentation/BookReferenceFormat.md)（[English](https://github.com/shelfsmith/StackNestViewerKit/blob/main/Documentation/BookReferenceFormat.en.md)）
- サンプルの参照ファイル: [Documentation/Samples](https://github.com/shelfsmith/StackNestViewerKit/tree/main/Documentation/Samples)

Swift で書くビューアは、パッケージ [StackNestViewerKit](https://github.com/shelfsmith/StackNestViewerKit)（MIT・依存なし）を SwiftPM で取り込めば、参照ファイルの読み取り・ページの取得・読書位置の書き戻しを、この文書どおりに行えます。StackNest も、参照ファイルをこのパッケージの型で書いています。

StackNest の設定（「StackNest と読書位置を同期する（対応アプリのみ）」）の説明は、アプリ内のヘルプ（⌘?）の「外部ビューア」にあります。この案内に替える前の全文は、このリポジトリの履歴にあります。
